Institutional platform connecting people, knowledge, institutions, opportunity, and markets.

## Live surfaces

| Surface | URL |
|---|---|
| Public site | https://peopleandyouth.org |
| Admin entry | https://peopleandyouth.org/admin/login |

| Investor CRM | https://peopleandyouth.org/admin/investor-crm |

## Tech stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16.2.12 (App Router, Turbopack) |
| Language | TypeScript 5.x |
| UI | React 19 + Tailwind CSS |
| Database | Supabase PostgreSQL |
| Auth | Supabase SSR (`@supabase/ssr`) |
| Storage | Supabase Storage (`investor-data-room` bucket) |
| Email | Resend |
| Payments | Razorpay |
| Hosting | Vercel |
| Cron | Vercel Cron (daily 06:00 UTC) |
